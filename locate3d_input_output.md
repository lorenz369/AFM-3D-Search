RGB Images (color/*.jpg): The standard color picture for each frame. This provides the texture and visual information.

Depth Maps (depth/*.png): A grayscale image where each pixel's brightness represents its distance from the camera. This is the crucial 3D information.

Camera Poses (pose/*.txt): For each frame, a text file containing a 4x4 transformation matrix. This matrix defines the exact position and orientation of the iPhone in 3D space for that specific moment.

Camera Intrinsics (intrinsic/*.txt): A text file containing the camera's internal parameters, like its focal length. This is needed to accurately project the 2D image data into 3D space. It usually only needs to be saved once per recording session.
