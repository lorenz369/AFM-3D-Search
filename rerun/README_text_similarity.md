# Text-Based Similarity Highlighting for Featurized Point Clouds

This feature adds semantic text-based search capabilities to the featurized point cloud visualization using CLIP embeddings.

## 🎯 Overview

The text-based similarity highlighting feature allows you to:
- Query your 3D point cloud using natural language descriptions
- Find and highlight points that are semantically similar to your text query
- Visualize similarity scores and statistics
- Use any CLIP-supported text query for semantic search

## 🔧 Requirements

- CLIP model (automatically installed with the `clip-by-openai` package)
- Featurized point clouds with CLIP embeddings (generated by MASt3R preprocessing)
- Python packages: `torch`, `numpy`, `sklearn`

## 🚀 Usage

### Basic Text Query

```bash
python visualize_featurized_pointcloud.py /path/to/pointcloud/dir \
    --text-query "chair" \
    --enable-highlights
```

### Advanced Options

```bash
python visualize_featurized_pointcloud.py /path/to/pointcloud/dir \
    --text-query "wooden chair with blue cushion" \
    --enable-highlights \
    --text-similarity-top-k 200 \
    --text-similarity-threshold 0.25 \
    --clip-model-version "ViT-L/14" \
    --point-size 0.02 \
    --create-mesh
```

### Interactive Testing

Use the test script for easy experimentation:

```bash
# Single query
python test_text_similarity.py /path/to/pointcloud/dir --query "tree"

# Interactive mode
python test_text_similarity.py /path/to/pointcloud/dir --interactive
```

## 📋 Command Line Arguments

### Text-Based Similarity Options

| Argument | Type | Default | Description |
|----------|------|---------|-------------|
| `--text-query` | str | None | Text query for semantic search |
| `--text-similarity-top-k` | int | 100 | Number of most similar points to highlight |
| `--text-similarity-threshold` | float | 0.3 | Minimum cosine similarity threshold |
| `--clip-model-version` | str | "ViT-B/32" | CLIP model version ("ViT-B/32" or "ViT-L/14") |

### Required for Text Search

- `--enable-highlights`: Must be enabled for text-based highlighting
- Point cloud must contain CLIP features (generated during preprocessing)

## 🎨 Visualization Features

### Highlighting Colors

- **Golden/Yellow**: Text similarity highlights
- **Color Intensity**: Represents similarity strength (brighter = more similar)
- **Point Size**: Highlighted points are slightly larger for visibility

### Available Views in Rerun

When using text queries, you'll see these additional views:
- `world/text_similarity_highlights`: Points matching your text query
- `text_search/query`: Your current text query
- `text_search/num_matches`: Number of matching points found
- `text_search/top_similarity`: Highest similarity score
- `text_search/mean_similarity`: Average similarity score

## ⚙️ Technical Details

### How It Works

1. **Text Encoding**: Your text query is encoded using CLIP's text encoder
2. **Feature Comparison**: The encoded text is compared with CLIP features of each point using cosine similarity
3. **Filtering**: Points above the similarity threshold are selected
4. **Ranking**: Top-k most similar points are highlighted
5. **Visualization**: Highlighted points are shown in golden/yellow with intensity based on similarity

### Similarity Scoring

- **Cosine Similarity**: Measures semantic similarity between text and visual features
- **Range**: -1 (completely opposite) to +1 (perfectly similar)
- **Typical Values**: 0.2-0.8 for meaningful matches
- **Threshold**: Adjustable, lower values show more results

### Performance Tips

- **Model Selection**: 
  - `ViT-B/32`: Faster, good for most use cases
  - `ViT-L/14`: More accurate, slower processing
- **Top-k Setting**: Lower values for focused results, higher for comprehensive search
- **Threshold Tuning**: Start with 0.2-0.3, adjust based on results

## 🐛 Troubleshooting

### Common Issues

1. **"CLIP encoder not available"**
   - Install CLIP: `pip install clip-by-openai`
   - Check CUDA availability for GPU acceleration

2. **"No CLIP features available"**
   - Ensure point cloud was preprocessed with CLIP features enabled
   - Check that `features_clip` exists in the `.pt` file

3. **"No points found matching query"**
   - Lower the similarity threshold (try 0.1-0.2)
   - Try simpler, more general queries
   - Check if CLIP features are properly loaded

4. **Poor results**
   - Use more specific/descriptive queries
   - Try different CLIP model versions
   - Adjust top-k parameter
